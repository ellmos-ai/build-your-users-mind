## Zero-Copyleft Guarantee & Unprivileged Execution

- Zero-Copyleft Guarantee: All runtime code and development dependencies are governed strictly by permissive, business-friendly open-source licenses (MIT, Apache-2.0, PSF-2.0). The codebase contains zero GPL, AGPL, or viral copyleft components.

## Governance & Runtime Invariants

build-your-users-mind strictly enforces ten foundational governance and runtime invariants:
- INV-LOCAL-01: Zero-Egress / 100% Offline (all interaction logs, extracted corpora, chunks, and predictions stay strictly on local disk; zero cloud telemetry)
- INV-LOOPBACK-02: Strict Loopback Boundary in Secure-Mode (secure_text_avatar only connects to 127.0.0.1/localhost, http only, never external)
- INV-REDACT-03: Multi-Pass Redaction & Fail-Closed Privacy (heuristic redaction passes, domain sanitization, never commit real logs)
- INV-DETERMINISTIC-04: Stable Identifiers & Reproducible Scoring (deterministic hashing, stable chunking, calibration metrics)
- INV-SEPARATION-05: Strict Boundary Between Recommendation and Execution Authority (predictions never authorize execution)
- INV-APPEND-06: Append-Only Decision Stream (revalidated journal with hash verification and receipt tracking)
- INV-MULTIHOST-07: Multi-Host Parity & Lock Defense (defense against sync conflicts, lock files, multi-host file collisions)
- INV-UNPRIV-08: Unprivileged Execution (RunAsInvoker standard user-mode, zero elevation required)
- INV-PORTABLE-09: Zero Runtime Dependencies (pure Python 3.10+ standard library)
- INV-SLA-10: Transparent Open-Source SLA (permissive MIT license, multi-OS CI matrix, committed 48h security SLA)
